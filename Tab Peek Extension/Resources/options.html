Tab Peek Settings

Changes are saved as soon as you make them.

Thumbnails

Tab Peek saves a small screenshot of each tab you view. When there are more than this, the oldest ones are deleted. More thumbnails use more disk space.

Theme

Auto follows macOS (System Settings → Appearance). Light or Dark keeps Tab Peek's popup and this page in that look, whatever macOS uses.

How tall the list of tabs can grow before it starts scrolling. Taller shows more tabs at once.
The screenshot area above the tab list. Turn it off for a short, plain list you only search and click. Thumbnails are still saved, so turning it back on shows them again.
ms How long the mouse has to rest on a tab in the list before its preview appears. Shorter feels quicker. Longer avoids previews flashing by as you move across the list. 1000 ms is one second.
The faint "Hover a tab to preview it" text next to All windows in the popup.
